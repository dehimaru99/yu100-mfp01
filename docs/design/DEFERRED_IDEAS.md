# Deferred Design Ideas

Ideas recorded here are intentionally outside the active MFP implementation scope.

## Multiple Supply Routes

Potential later extension: provide multiple routes to the same destination with different risk / return / capacity / resilience profiles.

Examples:

- short / dangerous / high-capacity route;
- long / safer / lower-capacity route;
- weather-sensitive route;
- redundant backup route.

Each route should retain its own bottleneck semantics. Route selection could then become a strategic trade-off rather than a linear upgrade path.
