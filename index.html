勇者百年計画 — MFP02.7

Gate A / Actionable Diagnosis

Mission

WHY — 北部集落の生活備蓄が不足している
冬までに安定した補給路を確保できなければ生活を維持できない。

北部補給路の確立

Sector 10まで、継続的な輸送に使える補給路を確立する。

時間と資源
1遠征1か月
北部集落 生活備蓄北部側の実在する備蓄。補給不足なら月ごとに減る
本部運用余力遠征準備・補充・医療・回収をまとめた抽象的な組織資源
遠征携行物資今回の遠征継続余力。本部運用余力が低いほど上限が下がる
判定条件
MISSION COMPLETESector 10まで補給路運用可能
MISSION FAILED北部生活備蓄または本部運用余力が尽きる
遠征成果Mission状態とは別に「目標達成 / 前進あり / 前進なし」で表示
Gate A再検証。未達時は「主因 → このSectorで効く能力 → 現編成 → 次に変える具体的レバー」を同じ診断内に表示する。Simulation式そのものは変更しない。

Roster

Risk / Cohesion / Discipline / Ambition の内部値や性格ラベルは表示しない。能力と実際の提案・判断・事後評価・履歴から人物像を推測する。

Formation

4人と隊長を決める。隊長を切り替えると、現在のMission / Policyを前提にした判断傾向の概算を動的に表示する。
